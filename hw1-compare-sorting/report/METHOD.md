# 실험 방법

- C17, -O2 -Wall -Wextra -Wpedantic. 하드웨어·운영체제·컴파일러: data/environment.txt.
- Record = int key + size_t tag. 이 환경에서 sizeof(Record)=16. key만 비교한다.
- 크기 256,512,1024,2048,4096,8192; 입력 random, sorted, reversed, few_unique, nearly_sorted.
- xorshift32, 시드 20260922,20260923,20260924. 무작위 key 범위 -500000..500000.
- few_unique는 key 0..7. nearly_sorted는 오름차순 입력에 n/100번 무작위 인접 교환.
- 시드별 5회, 조합별 15개 시간 표본. sorted/reversed는 시드가 바뀌어도 동일 입력이다.
- 1회 워밍업 후 약 5ms 목표 배치를 정한다. 최대 4096개 배열, 입력 배치 메모리 상한 64MiB.
- 정렬 전 배치 배열을 복사하고, 정렬 후 결과를 검증한다. 생성·복사·검증은 시간에서 제외.
- clock()의 프로세스 CPU 시간 사용. 배치 총시간/배치 크기로 한 번의 시간을 얻는다.
- 알고리즘 실행 순서를 반복·시드에 따라 순환한다. 타이밍은 Stats=NULL로 수행한다.
- 비교·이동 횟수는 별도 계측 실행. 비교는 key 비교, 이동은 Record 1개 저장, 교환=3회.
- 컴파일러가 수행하는 실제 기계 명령 수나 함수 인자 복사 수는 이동 횟수가 아니다.
- buffer_bytes는 명시적 원소 저장 공간. 삽입/힙의 임시 Record 하나, 병합의 n개 버퍼.
- 모두 반복형이므로 재귀 없음. 지역 인덱스, 포인터, 호출 프레임, 할당기 관리 비용 제외.
- 병합은 bottom-up, 동일 key는 왼쪽 우선. 매 단계 버퍼로 복사 후 원본에 되쓴다.
- 병합에 이미 정렬된 경계 생략 최적화를 넣지 않음. malloc/free는 측정 시간에 포함.
- 중앙값과 25/75 분위수를 사용. 분위수는 Python statistics.quantiles(method='inclusive').
- 제한: 단일 기기, 유한 입력 범위, 작은 표본 수. 실험값만으로 점근적 복잡도나 보편적 우열을 증명하지 않음.

## 큰 입력 실험
- 무작위 입력만 8,192~1,048,576을 두 배씩 늘린다.
- 삽입은 65,536까지 실행하고 그 이후는 사전에 정한 실행 비용 상한으로 생략한다.
- 시드별 3회, 조건별 9개 시간 표본. 원본 large-raw.csv 180행.
- 기본 실험과 동일한 코드의 --large 옵션이며, 별도 실행이라 중복 크기의 시간도 달라질 수 있다.
