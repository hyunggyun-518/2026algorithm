# 측정·분석 사전 규약 v1

이 규약은 6단계에서 본 실험 전에 고정했다. `data/core_manifest.csv`와 `data/size_manifest.csv`가 입력 사례의 기준이다. 실행기는 저장된 목록과 재생성 목록의 바이트 단위 일치를 먼저 검사하며, 다르면 측정을 중단한다. 결과가 마음에 들지 않는다는 이유로 사례·시드·분석 지표를 바꾸지 않는다. 변경이 필요하면 이유와 버전을 별도로 남기고 이전 결과를 보존한다.

## 사례와 순서

- 핵심: 101×101, 열린 지도·장벽 지도·미로, 가까운/먼 목표, 시드 0~11의 72개 사례. 유형과 거리별 12개씩이다.
- 크기 보조: 열린/장벽 지도, 먼 목표, 51·101·201 크기, 시드 0·2·4·6·8·10. 36개 조합 중 101 크기 12개는 핵심 결과를 재사용하고, 나머지 24개만 추가 측정한다. 따라서 보조 비교는 같은 유형·시드의 크기별 짝을 사용한다. 미로는 크기에 따라 구조 변화가 커 해석이 어려워 보조 실험에서 제외한다.
- 예비실험: `open-near-101-00`, `barrier-far-101-00`, `maze-far-101-00` 세 사례. 본 실험의 통계 요약에는 포함하지 않는다.
- 사례 순서는 `sha256("case-order-v1:" + case_id)` 오름차순이다. 지도 생성과 최단 이동 칸 수 계산은 측정 전에 수행한다.
- 각 사례에서 알고리즘별 1회 준비 실행을 한 뒤, 3회씩 측정한다. 회차마다 `(사례 순번 + 회차 번호) mod 3`칸 순환해 세 알고리즘이 첫째·둘째·셋째 순서에 각각 한 번씩 놓인다. 회차 번호는 내부적으로 0부터 계산하고 CSV에는 1부터 기록한다.

## 측정 범위와 검증

`perf_counter_ns()`의 두 호출 사이에는 탐색 함수 호출만 들어간다. A*가 함수 내부에서 수행하는 최소 이동 비용 확인과 세 방식의 경로 복원은 포함한다. 지도 생성, 준비 실행, 경로 검사, 파일 저장, 그래프 생성은 제외한다. 한 머신·한 Python 환경에서 본 실험과 크기 보조 실험을 실행하고, 각 실행의 시간·Python 버전·플랫폼·규약 및 목록 해시를 `.meta.json`에 저장한다. 저장된 결과 파일은 덮어쓰지 않고 새 버전 이름을 쓴다.

원시 CSV는 사례 정보, 격자 해시, 최단 이동 칸 수, 실행 순서, 경과 나노초, 도달·비용·경로 칸 수, 확장 정점 수, 우선순위 큐 삽입·꺼냄 횟수를 한 실행당 한 행으로 기록한다. 준비 실행에서 세 방식의 최적 비용이 일치해야 한다. 각 측정 실행도 실제 경로의 진입 비용과 반환 비용, 준비 실행의 비용이 일치해야 한다. 미도달·경로 오류·중복·누락은 실패이며 숫자를 대체하지 않는다.

## 사전 분석 기준

핵심 비교의 단위는 지도 사례다. 같은 사례·알고리즘의 3회 경과 시간 중앙값을 대표 시간으로 쓰고, 확장 정점 수는 결정적 값으로 기록한다. 각 사례에서 A*와 양방향 Dijkstra의 시간/확장 정점 수를 Dijkstra와 짝지어 `후보 ÷ Dijkstra` 비율로 계산한다. 6개 유형×거리 묶음마다 12개 사례 비율의 중앙값과 사분위 범위, 비율이 1보다 작은 사례 수를 함께 제시한다. 사분위수는 정렬된 12개 값의 하위 6개 및 상위 6개 중앙값으로 정의한다. 전체 72개 결과도 보여 주되, 유형별 차이를 지우는 단일 순위로 해석하지 않는다. 예상과 반대인 사례를 숨기지 않고 격자 해시와 탐색 지표를 이용해 원인을 검토한다. 탐색 확장 수와 실행 시간의 방향이 다르면 큐 작업·초기화 등 구현 비용을 함께 살핀다.

보조 실험은 유형·시드가 같은 사례의 크기별 시간 및 확장 수를 기술적으로 비교한다. 크기만 바뀌어도 실제 최단 거리와 지형이 달라질 수 있으므로, 최단 이동 칸 수와 맨해튼 거리도 함께 제시한다. 3개 크기의 관측만으로 점근적 시간복잡도를 입증하거나 일반적인 우월성을 주장하지 않는다. 시간 변동은 세 반복의 최솟값·최댓값과 실행 환경으로 설명하며, 이 설계로 유의확률이나 보편적 성능 보장을 주장하지 않는다.

최종 선택 기준은 결과를 본 뒤 사용자가 정한다. 보고서에는 어느 유형·거리·크기에서 어떤 지표를 우선했는지와 예외를 명시한다. 선택 기준을 사후에 정했다는 사실과 사전 고정한 측정·분석 규칙을 구분한다.

## 6단계 예비실험

`data/raw/pilot_v1.csv`에는 3개 사례×3개 알고리즘×3회, 총 27행이 누락 없이 기록되었다. 비용은 사례별로 세 방식이 일치했고, 경로 검사도 통과했다. 실행 환경과 설정은 `data/raw/pilot_v1.meta.json`에 있다. 9개 사례별 중앙값은 `data/raw/pilot_v1_summary.csv`에 저장했다. 이 작은 예비실험은 도구의 동작 가능성을 확인할 뿐, 성능 결론에 쓰지 않는다.

재검사 명령:

```sh
make test
python3 -m experiments.summarize data/raw/pilot_v1.csv
```

7단계에서 핵심 72개, 8단계에서 추가 24개를 실행한다. 각 실행은 기록된 원시 결과와 메타데이터를 함께 커밋한다.
