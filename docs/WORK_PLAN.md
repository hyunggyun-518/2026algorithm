# 단계별 작업 계획

작업은 `feature/pathfinding-project` 브랜치에서 진행한다. 과제1의 `feature/hw1-compare-sorting` 브랜치는 변경하지 않는다. 각 단계는 테스트·결과 확인·커밋·push 후 사용자에게 보고하고, 다음 단계는 별도 요청을 받은 뒤 시작한다.

| 단계 | 이름 | 완료 기준 |
|---|---|---|
| 1 | 저장소와 문제 규칙 정하기 | 프로젝트 브랜치, 규약, 실행 뼈대, 테스트 |
| 2 | Dijkstra 기준선 만들기 | 경로 복원과 독립 검증기 통과 |
| 3 | A* 만들기 | 허용적 휴리스틱과 최적성 검사 통과 |
| 4 | 양방향 탐색 만들기 | 안전한 종료·역방향 비용·경로 복원 검사 통과 |
| 5 | 비교용 지도 만들기 | 핵심 72개 사례를 시드로 재생성 |
| 6 | 측정 도구와 예비실험 | 원시 CSV 형식과 본 실험 설정 고정 |
| 7 | 본 실험 돌리기 | 핵심 사례 결과 수집·누락과 최적성 검사 |
| 8 | 결과 읽고 크기·반례 확인하기 | 추가 24개 크기 사례, 그래프·해석·선택 기준 후보 |
| 9 | 최종 보고서 쓰기 | 사용자 판단을 반영한 5~20쪽 PDF 검수 |
| 10 | 남이 그대로 돌려보기 | 깨끗한 환경 재현과 URL·ZIP·PDF 확인 |

최종 제출 예정일은 **2026-12-13 23:59**다. 진행 상태와 실제 결과는 완료한 단계에서만 갱신한다.
