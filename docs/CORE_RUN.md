# 7단계 핵심 실험 실행 기록

6단계에서 고정한 [측정·분석 규약](MEASUREMENT_PROTOCOL.md)과 `data/core_manifest.csv`를 변경하지 않고 핵심 사례를 실행했다. 결과는 `data/raw/core_v1.csv`, 실행 환경·순서·목록 해시는 `data/raw/core_v1.meta.json`에 보존했다. 별도 예비실험 결과를 본 실험 행에 합치지 않았다.

## 실행과 검증

```sh
python3 -m experiments.measure core --output data/raw/core_v1.csv
python3 -m experiments.verify core data/raw/core_v1.csv
make test
```

기존 결과 파일은 덮어쓸 수 없으므로 재측정할 때는 새로운 버전 이름을 사용한다. 동일 숫자를 다시 얻는다는 뜻이 아니라 같은 사례·측정 규칙·검증 과정을 재현한다는 뜻이다. 경과 시간은 시스템 상태에 따라 달라질 수 있다.

실행 환경은 macOS 27.0.1 arm64, Python 3.13.12로 6단계 예비실험과 일치한다. 실행기는 각 사례에서 세 방식의 준비 실행 결과와 실제 경로 비용을 확인하고, 측정 후 모든 경로·비용을 검증한 뒤 파일을 저장했다. 저장된 파일을 다시 읽는 검증기는 입력 목록의 해시, 정확한 사례·순서·반복, 양수인 경과 시간, 동일 사례의 최적 비용 일치, 반복별 결정적 지표의 일치를 확인했다.

검증 결과는 **72개 사례, 648개 측정 행, 사례·방식별 216개 묶음**이다. 각 묶음에는 3회 측정이 빠짐없이 있다. 결측·중복·미도달·비용 불일치는 없었다. 세 반복의 `최댓값 ÷ 최솟값`은 216개 묶음에서 중앙값 1.016이며, 1.5를 넘는 묶음은 없었다. 이는 이번 실행의 내부 안정성 점검이지 다른 환경에서의 시간 재현을 보장하지 않는다.

원시 파일의 SHA-256은 `d4428e83dfe097e6f765512e8f61572399dca4cc349df9e6cff6cd7dbf65ba29`, 메타데이터 파일은 `d44ea2522a07b85e82602b63c6b54ab2dc991c39455a72254418220441767fbe`다.

이 단계에서는 알고리즘 순위를 결론으로 내리지 않는다. 8단계에서 사전 고정한 유형·거리별 짝지은 비교, 추가 24개 크기 사례, 반례 검토를 수행한다.
